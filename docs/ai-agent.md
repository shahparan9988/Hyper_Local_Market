\# AI Agent



\## Goal



Allow users to ask questions about their shop, orders, customers, products, and sales.



\## Example questions



\- What were my sales this week?

\- Which product sells most?

\- Which customer orders frequently?

\- What stock is running low?



\## Safety rules



AI must not directly modify production data.



AI should use:

\- Read-only tools

\- Permission checks

\- Audit logs

\- Approved query handlers

\- Read models
